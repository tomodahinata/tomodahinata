### 1. 木材流通DX SaaS — 🏆 経済産業大臣賞 受賞 / 京都府認定
**Excel・FAX・電話**で回っていた業界の受発注を、**統合Web SaaS** に置き換え。アナログ業務をゼロから設計・開発・インフラ構築まで一人で実現し、**経済産業大臣賞**および**京都府の認定**を取得。
> `業界DX` `B2B SaaS` `サブスクリプション` `要件定義→運用まで一人完結`

### 2. RAG音声接客AI — 精度90%超 / レスポンス70%改善
社内ドキュメントを学習させた **RAG音声チャットボット**を実運用レベルで構築。
- ✅ 回答**精度 90%超**
- ✅ レスポンスを **70%改善（約5秒 → 約1.5秒）**
> `RAG` `AWS Bedrock` `Claude` `pgvector` `Whisper` `LangChain`

### 3. インバウンド向け 飲食店マッチング — 満足度90%超
外国人旅行客と飲食店をつなぐ toC サービス。Tinder風UI・多言語対応、高トラフィック/UXに耐える設計。
- ✅ ユーザー**満足度 90%超**
> `Next.js` `Go(並列処理)` `多言語` `署名付きURL等のセキュア設計`
